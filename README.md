# 📖 Vuora

> [English version](README.en.md) is also available.

**Web ブラウジングを快適にする 12 機能** を 1 つのポップアップに統合した Chrome / Firefox 拡張機能です。
インストール直後はすべて OFF、必要な機能だけ自分で ON にする **オプトイン方式**。外部送信ゼロ・個人情報収集ゼロ。

---

## ✨ 機能一覧

| 機能 | 概要 |
|------|------|
| 🧹 **YouTube 機能拡張** | Shorts 削除 / コメント欄非表示 / ライブチャット非表示 / 登録チャンネル一覧グリッド化 / 接続モニター / 配信時刻オーバーレイ（アーカイブに配信時の時刻を表示）/ 海外チャンネル除外 / Gemini Notebook 送信 など **34 サブ機能** |
| 🐦 **X クリーナー** | 右ペイン（消したぶんタイムラインを拡幅）/ トレンド / おすすめユーザー / 広告投稿 / プレミアム勧誘 / Grok / 反応数 を非表示 + ホームを「フォロー中」で開く (**9 サブ機能**) |
| 📦 **Amazon 定期おトク便 月別合計** | 配送月ごとの合計金額を計算して `/auto-deliveries` ページに表示 |
| 🏆 **Amazon ランキングへ移動ボタン** | 商品ページ詳細欄のランキングリンクを集約、一番細かいサブカテゴリへワンクリック移動 |
| 📦 **Amazon 販売元・出荷元バッジ** | 商品ページ上部に「販売: XXX / 出荷: YYY」を表示。Amazon 直販 = 🟢 緑、マーケット出品 = 🟠 オレンジ警告 |
| 📷 **Instagram クリーナー** | Reels / Explore / ストーリー / Threads 誘導 など冗長 UI を非表示 + 画像ダウンロード (**11 サブ機能**) |
| 🎵 **TikTok クリーナー** | コメント欄 / おすすめのアカウント 非表示 + 画像ダウンロード (**3 サブ機能**) |
| 🔊 **音量ブースター** | タブ音声を 0〜300% 増幅。自動歪み防止 / ナイトモード / 壁ドン対策モード（低音カット）/ ミュート + **10 バンドグラフィックイコライザ (プリセット同梱)** 対応 |
| 🎞️ **動画ガンマ補正** | スライダーで `<video>` の明るさを調整 (中央 1.0 = 補正なし、左で暗く、右で明るく) |
| 🖥️ **動画の黒帯除去** | ウルトラワイド画面で上下/左右の黒帯をズーム or 引き伸ばしで除去 |
| 🔍 **ルーペ** | マウス追従の円形拡大鏡。動画を一時停止して細部を確認するのに便利 |
| 🎨 **カラーピッカー** | 画面上の色を採取して HEX / RGB / HSL でコピー、最大 20 件の履歴付き |

> 📥 **画像ダウンロード**は Instagram / TikTok クリーナーのサブ機能として提供されます (投稿写真・動画サムネにホバー時 DL ボタンを表示)。YouTube では未提供です。

## 💾 インストール

### Chrome / Edge

[Chrome Web Store](https://chrome.google.com/webstore) で **「Vuora」** を検索してインストール。

### Firefox (142 以降)

[addons.mozilla.org](https://addons.mozilla.org/) で **「Vuora」** を検索してインストール。

> Firefox 版でも **全 12 機能が利用できます**。音量ブースターは Firefox 専用のページ内音声処理（MediaElementSource）で動作し、popup を開かなくても設定が全タブに自動適用されます（タブ共有バナーも出ません）。制約は 1 つだけ: DRM 保護動画のサイト（Netflix / Prime Video / DAZN / Disney+ 等）では音量ブースターは効きません（動画は普通に再生されます）。

## 🚀 使い方

1. 拡張機能アイコンをクリックしてポップアップを開く
2. **使いたい機能のマスタートグルだけ ON にする** (初期状態は全部 OFF)
3. 機能ごとの詳細設定 (YouTube 機能拡張の 34 サブ機能、音量ブースターのスライダー等) はポップアップ内で調整
4. 設定は次回以降も保持されます

### popup タブ構成
- **調整**: 11 マスタートグル + 音量スライダー + ガンマ / ルーペ
- **YouTube**: YouTube 機能拡張のサブ機能 34 個
- **X**: X クリーナーのサブ機能 9 個
- **Instagram**: Instagram クリーナーのサブ機能 11 個
- **TikTok**: TikTok クリーナーのサブ機能 3 個
- **カラーピッカー**: EyeDropper 起動 + 履歴

## 🔒 プライバシー

- **外部送信ゼロ** — 本拡張機能はサーバーに何も送信しません
- **個人情報の収集なし** — すべての処理はあなたの端末内で完結します
- **オプトイン方式** — インストール直後はすべて OFF、有効化したものだけ動作
- **オープンソース** — コードはこのリポジトリで公開、誰でも検査可能

詳細は [プライバシーポリシー](docs/privacy-policy.md) を参照してください。

## 🛡️ 必要な権限

| 権限 | 用途 |
|------|------|
| `activeTab` | popup から active tab を操作 (音量ブースター・ルーペ等) |
| `storage` | 設定の永続化 (`chrome.storage.local`) |
| `offscreen` | 音量ブースターの AudioContext / GainNode チェーンを Service Worker 外で維持するため |
| `tabCapture` | 音量ブースターでタブ音声を取得して 0〜300% 増幅するため (全サイト共通) |
| `host_permissions: <all_urls>` | ルーペが popup 自動クローズ後・SPA navigation 後でも画面キャプチャを取れるよう保証 (実質アクセス範囲は content_scripts 注入と同等) |

## 🐛 トラブルシュート

| 症状 | 対処 |
|------|------|
| **設定したのに効かない** | popup を一度閉じて開き直す。それでもダメなら拡張機能を 🔄 リロード |
| **YouTube のサイドバーから Shorts が消えない** | YouTube 機能拡張 > Shorts サブ機能 4 つ (棚 / チップ / サイドバー / ボタン) が個別 ON か確認 |
| **音量ブースターが効かない (Chrome)** | 音量ブースターは popup を開いた瞬間にアクティブタブで boost 開始します (user gesture 必須・Netflix 等の EME 動画含む全サイト共通)。動画再生中に popup を開いて音量を変えてみてください。ブースト中のタブには「このタブのコンテンツは共有されています」バナーが出ます (tabCapture の仕様) |
| **音量ブースターが効かない (Firefox)** | Firefox 版はページ内音声処理 (MediaElementSource) で動作し、popup を開かなくても全タブに自動適用されます。DRM 保護動画のサイト (Netflix / Prime Video / DAZN / Disney+ 等) では仕様上効きません (動画は普通に再生されます)。設定変更後に効かない場合はページを再読み込みしてください |
