# 📖 Vuora

> [English version](README.en.md) is also available.

**Web ブラウジングを快適にする 12 機能** を 1 つのポップアップに統合した Chrome / Firefox 拡張機能です。
インストール直後はすべて OFF、必要な機能だけ自分で ON にする **オプトイン方式**。通常の閲覧支援処理は端末内で完結し、通信は明示した機能を有効化・実行したときだけ行います。

---

## ✨ 機能一覧

| 機能 | 概要 |
|------|------|
| 🧹 **YouTube 機能拡張** | Shorts 削除 / コメント欄非表示 / ライブチャット非表示 / 登録チャンネル一覧グリッド化 / 「関連が強い」欄の非表示 / 接続モニター / 配信時刻オーバーレイ（アーカイブに配信時の時刻を表示）/ 海外チャンネル除外 / ライブ遅延軽減 / 画質・速度・音量ボタン / Gemini Notebook 送信 など **39 サブ機能** |
| 🐦 **X クリーナー** | 右ペイン（消したぶんタイムラインを拡幅）/ トレンド / おすすめユーザー / メッセージドック / 広告投稿 / プレミアム勧誘 / Grok / 反応数 を非表示 + ホームを「フォロー中」で開く (**9 サブ機能**) |
| 📦 **Amazon 定期おトク便 月別合計** | 価格のない一覧でも Amazon から金額を取得して合計表示。現在価格や前回配送の単価で補う場合は参考合計として表示。従来の月別画面にも対応 |
| 🏆 **Amazon ランキングへ移動ボタン** | 商品ページ詳細欄のランキングリンクを集約、一番細かいサブカテゴリへワンクリック移動 |
| 📦 **Amazon 販売元・出荷元バッジ** | 商品ページ上部に「販売: XXX / 出荷: YYY」を表示。Amazon 直販 = 🟢 緑、マーケット出品 = 🟠 オレンジ警告 |
| 📷 **Instagram クリーナー** | Reels / Explore / ストーリー / Threads 誘導 など冗長 UI を非表示 + 動画シークバー + 画像ダウンロード (**12 サブ機能**) |
| 🎵 **TikTok クリーナー** | コメント欄 / おすすめのアカウント 非表示 + 画像ダウンロード (**3 サブ機能**) |
| 🔊 **音量ブースター** | タブ音声を 0〜300% 増幅。自動歪み防止 / ナイトモード / 壁ドン対策モード（低音カット）/ ミュート + **10 バンドグラフィックイコライザ (プリセット同梱)** 対応 |
| 🎞️ **動画ガンマ補正** | スライダーで `<video>` の明るさを調整 (中央 1.0 = 補正なし、左で暗く、右で明るく) |
| 🖥️ **動画の黒帯除去** | ウルトラワイド画面で上下/左右の黒帯をズーム or 引き伸ばしで除去 |
| 🔍 **ルーペ** | マウス追従の円形拡大鏡。動画を一時停止して細部を確認するのに便利 |
| 🎨 **カラーピッカー** | 画面上の色を採取して HEX / RGB / HSL でコピー、最大 20 件の履歴付き |

> 📥 **画像ダウンロード**は Instagram / TikTok クリーナーのサブ機能として提供されます (投稿写真・動画サムネにホバー時 DL ボタンを表示)。YouTube では未提供です。

## 💾 インストール

### Chrome / Edge

[Chrome Web Store](https://chrome.google.com/webstore) で **「Vuora」** を検索してインストール。

### Firefox (142 以降)

[addons.mozilla.org](https://addons.mozilla.org/) で **「Vuora」** を検索してインストール。

> Firefox 版でも **全 12 機能が利用できます**。音量ブースターはページ内で音声を処理し、popup を開かなくても設定が全タブに自動適用されます（タブ共有バナーも出ません）。ページ内でクリックなどの操作をした後、再生中の動画・音声が対象になります。DRM 保護動画のサイト（Netflix / Prime Video / DAZN / Disney+ 等）や、安全に音声を処理できない配信元では適用せず、通常再生を優先します。

## 🚀 使い方

1. 拡張機能アイコンをクリックしてポップアップを開く
2. **使いたい機能のマスタートグルだけ ON にする** (初期状態は全部 OFF)
3. 機能ごとの詳細設定 (YouTube 機能拡張の 39 サブ機能、音量ブースターのスライダー等) はポップアップ内で調整
4. 設定は次回以降も保持されます

YouTube の「動画ページ」には、ライブ遅延軽減と画質・再生速度・プレイヤー音量の切替ボタンがあります。各機能の「詳細設定」で表示するボタンや値、ライブ追従の動作を選べます。数値や画質はプルダウンから選択し、画質・速度・音量ボタンは押したときだけ適用します。ショートカットはブラウザの拡張機能設定で割り当てられます。

接続モニターとアーカイブの配信時刻も、画質・再生速度・音量と同じオーバーレイに分類名付きで表示します。各機能は個別に ON/OFF でき、接続モニターまたは配信時刻だけでも表示できます。専用の移動・折りたたみ操作はなく、項目が多いときは枠内をスクロールします。

ポップアップ下部の **「お問い合わせ」** から、使い方の質問・不具合報告・機能要望を送信できます。初回送信時はメールで届く6桁の確認コードによる本人確認があります。

### ポップアップのタブ構成

- **調整**: オーディオ / 映像 / Amazon の機能と詳細設定
- **YouTube**: YouTube 機能拡張のサブ機能 39 個
- **X**: X クリーナーのサブ機能 9 個
- **Instagram**: Instagram クリーナーのサブ機能 12 個
- **TikTok**: TikTok クリーナーのサブ機能 3 個
- **カラーピッカー**: 色の採取・入力・調整・コピー + 履歴
- **設定**: 複数PC間の設定同期 + 設定のエクスポート・インポート

YouTube / X / Instagram / TikTok のマスタートグルは、それぞれのタブにあります。

### Instagram の動画操作

「Instagram」タブでクリーナーを ON にし、「動画にシークバーを表示」を ON にすると、動画の再生位置をバーで変更できます。入力欄以外で **Space キー**を押すと、表示中の動画の再生・一時停止を切り替えます。投稿をモーダルで開いている場合は、その中の動画を優先します。

「投稿内の動画ブロック」が ON の投稿動画にはシークバーを表示せず、Space での再生も行いません。動画を操作したい場合はブロックを OFF にして、必要に応じて再生してください。ブロックを解除しても自動再開はしません。再生時間が未取得の動画やライブ動画などではシークバーが表示されない場合があります。

### 複数PC間の設定同期

ポップアップの「07 設定」タブにある「複数PC間で設定を同期」を各PCで ON にしてください（初期状態 OFF）。各PCで同じブラウザの同じアカウントを使い、ブラウザ設定でも拡張機能の同期を有効にしてください。Chrome と Firefox の間では同期できません。

初めて ON にしたときは保存済みの同期設定を優先し、まだ同期されていない項目はこのPCから保存します。その後は変更した項目を共有します。同じ項目を変更した場合は、設定変更時の更新情報が新しい方を優先します。別のサブ機能や別チャンネルの変更は両方残し、EQ はプリセットとバンド値を一組として扱います。時刻が同じ場合も全PCで同じ勝者を選びます。ただし、PCの時計ずれによって実際の操作順と一致しない場合があります。反映には時間がかかることがあります。

機能設定とチャンネル除外リストを同期します。認証情報・Gemini Notebook の送信先アカウント・採色履歴・表示タブ・HUD 位置は端末ごとに保持します。OFF にしてもPC内の設定と同期先のデータは残ります。失敗時は「同期を再試行」を押してください。設定と削除記録がブラウザの容量上限（全体約100 KB、保存区画ごとに約8 KB）に達すると同期に失敗します。削除記録は復活防止のため保持するので、除外リストを減らすだけでは容量が空かない場合があります。容量超過時もPC内の設定は残ります。

### 設定のエクスポート・インポート

「07 設定」タブの「エクスポート」でJSONファイルを保存し、「インポート」で読み込めます。全機能の設定、EQ、除外チャンネル、採色履歴、表示タブを含み、ChromeとFirefoxの間でも移せます。ファイルに含まれる設定キーを上書きし、含まれないキーは現在の値を保持します。サブ機能の設定は機能ごとにまとめて置き換わり、その中で省略された項目は既定値になります。

同期のON/OFF、Gemini Notebookの送信先アカウント、認証情報、キャッシュ、サイト上のHUD位置は端末ごとに保持します。同期がONのPCでは、読み込んだ機能設定も同期されます。不正な形式や5MBを超えるファイルは読み込みません。

## 🔒 プライバシー

- **通常処理は端末内で完結** — 外部通信は、Instagram / TikTok の画像取得、YouTube 接続モニター、Gemini Notebook 送信、お問い合わせフォーム、任意の設定同期、登録チャンネルのサムネイル取得、Amazon 定期おトク便の金額取得の7例外だけです。Amazon の取得は機能 ON 時のみ、認証 Cookie を Amazon にだけ送る読み取りです。現在価格や前回価格を含む参考合計は請求額が変わる可能性があり、クーポンは反映しません
- **個人情報は問い合わせ時だけ** — フォームへ入力したメールアドレスと問い合わせ内容は、送信操作をしたときだけ Kagayoi Support へ送られます
- **オプトイン方式** — インストール直後はすべて OFF、有効化したものだけ動作
- **オープンソース** — コードはこのリポジトリで公開、誰でも検査可能

詳細は [プライバシーポリシー](docs/privacy-policy.md) を参照してください。

## 🛡️ 必要な権限

| 権限 | 用途 |
|------|------|
| `activeTab` | popup から active tab を操作 (音量ブースター・ルーペ等) |
| `storage` | 設定の保存と、任意のPC間同期 (`chrome.storage.local` / `sync`) |
| `offscreen`（Chrome / Edge のみ） | 音量ブースターの音声処理をポップアップを閉じても維持するため |
| `tabCapture`（Chrome / Edge のみ） | 音量ブースターでタブ音声を取得して 0〜300% 増幅するため |
| `host_permissions: <all_urls>` | ルーペが popup 自動クローズ後・SPA navigation 後でも画面キャプチャを取れるよう保証 (実質アクセス範囲は content_scripts 注入と同等) |

Firefox では問い合わせの認証に必要な個人識別情報・認証情報のデータ利用許可をインストール時に確認し、問い合わせ本文を送信する前に追加で「個人的な通信」（`personalCommunications`）の許可を求めます。詳しくは [プライバシーポリシー](docs/privacy-policy.md#権限の使用目的) を参照してください。

## 🐛 トラブルシュート

| 症状 | 対処 |
|------|------|
| **設定したのに効かない** | popup を一度閉じて開き直す。それでもダメなら拡張機能を 🔄 リロード |
| **YouTube のサイドバーから Shorts が消えない** | YouTube 機能拡張 > Shorts サブ機能 4 つ (棚 / チップ / サイドバー / ボタン) が個別 ON か確認 |
| **音量ブースターが効かない (Chrome)** | 音量ブースターは popup を開いた瞬間にアクティブタブで boost 開始します (user gesture 必須・Netflix 等の EME 動画含む全サイト共通)。動画再生中に popup を開いて音量を変えてみてください。ブースト中のタブには「このタブのコンテンツは共有されています」バナーが出ます (tabCapture の仕様) |
| **音量ブースターが効かない (Firefox)** | ページ内で一度クリックなどの操作をしてから動画を再生してください。対応範囲と制約は [Firefox のインストール説明](#firefox-142-以降) を参照してください。設定変更後も効かない場合はページを再読み込みしてください |
