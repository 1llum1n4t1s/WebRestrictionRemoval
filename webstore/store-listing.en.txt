[Store Listing] tab
------------------------------------------------------------

■ Name (under 30 chars)
Web Viewing Assist

■ Summary (under 132 chars)
A Chrome extension that locally tunes the readability, audio, and continuity of the page you are viewing.

■ Description (under 16,000 chars)
An extension that consolidates 13 categories of viewing aids — plus a shared sub-feature (image download button on Instagram / TikTok) — into a single popup, all designed for comfortable everyday browsing.
(In v1.0.18 the former "restriction removal" features were retired; the Extension is now focused exclusively on web viewing assistance.)

■ Main features

· 🔄 Keep session alive (opt-in, default OFF)
  Mitigates idle-based session timeouts on sites such as SharePoint / Box.
  When the master toggle is ON, the top frame of every http(s) tab periodically dispatches synthetic mousemove / pointermove / scroll / focus events to reset the site's JS idle detection.
  Additionally, on SharePoint (*.sharepoint.{com,cn,de,us}) it tries a dedicated GET, and on other sites it tries a lightweight HEAD against the current URL / origin root from the top frame to help extend the server-side session.
  The popup slider lets you adjust the interval from 1 to 15 minutes (default 4 minutes).
  ※ Sites that reject HEAD or auth-proxy idle timeouts may not be helped by this feature.

· 📺 YouTube cleanup (opt-in, default OFF)
  Hides / removes Shorts from the sidebar / shelves / search results, and redirects /shorts/<id> URLs to /watch?v=<id>.
  In addition, the YouTube cleaner offers 30 fine-grained sub-features (search-result noise, filter-by-video-attribute, highlight, watch-page layout including comment & live-chat hiding, grid columns, subscriptions enhancements).

· 📦 Amazon Subscribe & Save monthly total (opt-in, default OFF)
  Shows a per-month total on https://www.amazon.co.jp/auto-deliveries.

· 🏆 Amazon jump-to-ranking button (opt-in, default OFF)
  The "Amazon Bestsellers Rank" links in a product's detail section appear in different positions on every page, making them hard to find. This consolidates a single "Go to this product's ranking" button at the top of the product info; clicking it navigates (same tab) to the most specific subcategory ranking. It only scans the bestsellers links inside the product-detail containers, so the button appears only on product pages that have a ranking link.
  ※ Pure DOM manipulation; no price/history reading or external transmission.

· 📦 Amazon seller / shipper badge (opt-in, default OFF)
  Extracts the seller and shipper from Amazon's hidden divs (#merchantInfoFeature_feature_div / #fulfillerInfoFeature_feature_div) and shows them as a non-clickable info badge ("📦 Sold: XXX / Ships: YYY") at the top of the product info, right next to the jump-to-ranking button. **Amazon-fulfilled and marketplace listings are visually distinguished** (Amazon-fulfilled = green badge / marketplace = orange warning badge), making it easy to spot suspicious marketplace listings at a glance. The detection uses Amazon's own isInternal flag (embedded JSON in the <script> inside #merchantInfoFeature_feature_div) as the primary signal, with the seller name as a fallback.
  ※ Pure DOM manipulation; no price/history reading or external transmission.

· 📷 Instagram cleaner (opt-in, default OFF)
  Hides Instagram's redundant UI through 11 sub-features.
  Main: Remove Reels (with URL redirect) / Remove Explore / Hide Stories tray / Stories URL → home / Hide Threads promotion
  Extras: Hide vanity counts / Block videos in posts / Hide comments / Hide Notes / Hide unread DM badge / Image download button
  ※ Client-side DOM and CSS only; nothing is transmitted externally.

· 🎵 TikTok cleaner (opt-in, default OFF)
  Hides TikTok's redundant UI through 3 sub-features.
  Main: Hide comments / Hide suggested accounts / Image download button
  ※ For direct photo / video URL access, the entire right panel is hidden; in the modal viewer (Browser Mode) only the comment list is hidden, preserving the profile.
  ※ Client-side DOM and CSS only; nothing is transmitted externally.

· 🔊 Volume Booster (opt-in, default OFF)
  Amplifies the active tab's volume from 0% to 300%. Turn the master toggle ON to enable the slider; the settings (gain value, sub-toggles, mute) are persisted globally. Since v1.0.33 the Volume Booster uses a MediaElementSource + tabCapture dual-path design: ordinary video sites (YouTube / X / Twitch / TikTok / Instagram / niconico, etc.) are boosted via the content script's MES path — **no user gesture required; the boost applies automatically without ever opening the popup** — while EME (DRM) heavy sites (Netflix / Prime Video / DAZN / Disney+ / Hulu / Apple TV+ / Abema / U-NEXT / TVer / Spotify, etc. — 15 hosts) are excluded from MES via a hostname blacklist and instead boosted through chrome.tabCapture + the offscreen document path triggered when the popup is opened (user gesture required). Both paths use the same 6-node chain — "Auto Volume Normalization (short-window RMS via AnalyserNode + auto GainNode) → Night-Mode compression (DynamicsCompressor) → manual GainNode for amplification → Auto Distortion Guard / limiter (DynamicsCompressor)" — which is the standard mastering layout (loudness correction → compression → make-up gain → limiter). The three sub-toggles (Auto Distortion Guard / Auto Volume Normalization / Night Mode) all default to OFF.
  The slider uses a logarithmic mapping over the 100..300% range so equal distance equals equal dB; gain changes are smoothed with a 45 ms ramp to suppress clicks. A mute 🔊/🔇 button sits at the left edge of the slider so you can silence the tab with one click while preserving the slider value and sub-toggle settings, and restore the original volume instantly with another click (this is an independent layer from Chrome's native tab mute). Even at 100%, if any of Auto Volume Normalization / Auto Distortion Guard / Night Mode / mute is ON, the AudioContext is preserved so use cases like "leave the volume alone but tame sudden peaks", "even out podcast voice levels", "tame loud night-time scenes", or "instant silence at 100%" still work. On tab switch, MES-path tabs are auto-applied; for the tabCapture path only tabs already being boosted are auto-reapplied and new tabs are applied once you open the popup and operate it.
  ※ Master OFF / slider 100% with all sub-toggles and mute OFF / tab closed / Extension disabled — any of these instantly releases the AudioContext and frees resources.
  ※ No recording, storage, or external transmission whatsoever.

· 🎞️ Video Gamma (opt-in, default OFF)
  Applies gamma correction to <video> elements on the page using SVG <feComponentTransfer type="gamma">. Master toggle + slider; the slider center (1.0) means no correction, left is darker (max 3.0), right is brighter (min 0.3). The setting is shared across tabs, and <video> elements inside iframes (e.g. YouTube embeds) also receive the same correction via all_frames: true.
  ※ Video data is not read, recorded, or transmitted; the feature only attaches an SVG filter, fully client-side.

· 🖥️ Remove video black bars (opt-in, default OFF)
  Removes the letterbox/pillarbox black bars seen on ultrawide monitors by Zoom (aspect-preserving crop) or Stretch (expand only the deficient axis) to fill the screen. Master toggle + display-mode selection + target-monitor preset; the video's aspect ratio is auto-detected from videoWidth / videoHeight. Shared across tabs, and <video> inside iframes also receive the same treatment via all_frames: true.
  ※ Video data is not read, recorded, or transmitted; the feature only applies a CSS transform, fully client-side.

· ✨ RTX Video Enhancer (opt-in, default OFF)
  Helps GPU drivers (e.g., NVIDIA RTX Super Resolution / AMD FidelityFX) detect video pages by injecting a 1×1 px invisible hint element on pages containing `<video>` elements. The driver-side feature itself must be enabled in the GPU settings (e.g., NVIDIA Control Panel); the Extension only handles the browser-side hint injection.
  ※ Zero external transmission. Only DOM injection — no video data is read or recorded.

· 🔍 Loupe (opt-in, default OFF)
  A circular magnifier that follows the mouse cursor. When the master toggle is ON, the active tab is captured as a JPEG snapshot via chrome.tabs.captureVisibleTab, attached as the background-image of a circular position: fixed lens (clip-path: circle()), and the background-position is updated at 60 fps with rAF coalescing on mousemove to magnify the area under the cursor. Because the captured pixels include video / iframe / canvas content, this is ideal for "pause a video and inspect fine details". Zoom is selected from 1.5× / 2.5× / 4× in the popup segment control; the lens diameter is adjustable 150–1000 px via a slider. Left-clicking the page while the lens is showing removes it instantly and flips the master toggle OFF. Re-capture is triggered automatically on initial activation / scroll (500 ms debounced) / large DOM changes (MutationObserver) / window resize.
  ※ The captured JPEG is converted to a Blob URL referenced only by the content script DOM, and is released via URL.revokeObjectURL on OFF. No recording, storage, or external transmission.

· 🎨 Color Picker (always available)
  The "Color Picker" tab in the popup uses the EyeDropper API to pick a color from anywhere on screen and copy it to the clipboard in HEX / RGB / HSL. Whether to include "#" in HEX is individually toggleable. Picked colors are kept on the device only as a specimen box (history) of up to 20 entries.
  ※ Nothing is recorded, stored, or transmitted; everything happens inside the popup.

■ How to use

1. Click the toolbar icon to open the popup.
2. Pick the feature you want via the popup's tab bar (Tune / YouTube / Instagram / TikTok / Color Picker).
3. Toggle on/off and tweak values via toggles and sliders inside each tab (auto-saved).
4. For Volume Booster and Video Gamma, drag the sliders directly.
5. On the "Color Picker" tab, trigger EyeDropper to pick a color from the screen.

Settings are auto-saved and restored on next launch.

■ Privacy

· No personal information or user data is collected.
· Settings are stored only on your device (chrome.storage.local).
· No communication with any third-party external servers.
  (When keep-session-alive's lightweight ping is ON, same-origin HEAD / GET requests may be issued against the user's enabled site itself.)
  (When the Instagram / TikTok image download button is ON, an image GET is issued against each site's official CDN (*.cdninstagram.com / scontent-*.fna.fbcdn.net / *.tiktokcdn.com / *.tiktokcdn-us.com) only at the moment the user clicks. credentials:omit + redirect:manual + referrerPolicy:no-referrer block cross-origin auth-info transmission, and a hostname allowlist blocks proxy fetches to any other origin.)
· While Volume Booster is in use, tab audio data is only amplified and re-output through an AudioContext; no recording, storage, or external transmission is performed.

■ Permission justifications (concise, ~40–60 chars)

  activeTab:
  Used to apply settings to the current tab from the popup, and to determine the target tab for the Volume Booster.

  storage:
  Used to persist feature toggles, slider settings, and color-picker history on the device (chrome.storage.local).

  offscreen:
  Used to maintain the Volume Booster's AudioContext / GainNode / DynamicsCompressor chain outside the Service Worker. Since v1.0.33 this is primarily used as the fallback path for EME (DRM) heavy sites (ordinary sites use the content script's MediaElementSource path).

  tabCapture:
  Used by the Volume Booster to capture tab audio and apply 0–300% normalization, compression, and amplification via AudioContext. Since v1.0.33 this is primarily used as the fallback path for EME (DRM) heavy sites listed in a hostname blacklist (Netflix / Prime Video / DAZN, etc. — 15 hosts). Ordinary sites use the content script's MediaElementSource path which applies automatically without requiring a user gesture.

  <all_urls> (host permission):
  Used by the Loupe feature to call chrome.tabs.captureVisibleTab and display the active tab's visible region as a magnified JPEG image in a circular lens. The activeTab permission alone can be revoked early after popup close or SPA internal navigation, blocking the capture. Adding <all_urls> ensures the Loupe runs reliably. The effective access scope is unchanged because content_scripts already inject on all http(s) sites.

■ Host-permission justifications

  http://*/* and https://*/*:
  Required so that the keep-session-alive, Video Gamma, and Remove-video-black-bars content scripts can be injected on all http(s) sites.
  (1) Keep session alive: the injected content script starts the poller on every http(s) tab when the master toggle is ON in the popup, and dispatches synthetic mousemove / pointermove / scroll / focus events. The HTTP ping is a separate sub-toggle (default OFF) and only fires same-origin HEAD / GET when ON.
  (2) Video Gamma: when the master toggle is ON, the Extension injects CSS that applies an SVG filter (url(#__cpa-video-gamma)) to <video> elements, plus an SVG <feComponentTransfer type="gamma"> definition, into <body>. To cover all tabs and all frames (including <video> in iframes), the script runs on http://*/* + https://*/* with all_frames: true.
  Neither feature reads, modifies, or transmits the page DOM (Video Gamma only attaches a filter to <video>; it does not read or save video data).

  *://*.youtube.com/*:
  Required for the YouTube cleaner (30 sub-features including Shorts removal and subscriptions enhancements). Search-result noise removal, watch-page decoration (comment hiding / live-chat collapse), home grid column count, /shorts/<id> → /watch?v=<id> redirect, and the /feed/channels grid view are all implemented via DOM/CSS only. Nothing read is transmitted off-device.

  *://www.amazon.co.jp/auto-deliveries*:
  Required to show a per-month total on the Amazon recurring-delivery page. The script reads `subscription-price` per month and inserts the computed total into the same page. Nothing read is transmitted off-device.

  *://www.amazon.co.jp/*:
  Required for the Amazon jump-to-ranking button + Amazon seller / shipper badge.
  (1) Jump-to-ranking button: scans only the "Amazon Bestsellers Rank" links (a[href*="bestsellers/"]) inside the product-detail containers and inserts a consolidated button at the top of the product info that links to the most specific subcategory. Self-gates to product pages.
  (2) Seller / shipper badge: extracts the seller and shipper from #merchantInfoFeature_feature_div / #fulfillerInfoFeature_feature_div hidden divs and shows them as a badge at the top of the product info (Amazon-fulfilled = green badge / marketplace = orange warning badge). The Amazon-fulfilled detection uses Amazon's own isInternal flag (embedded JSON in the <script> inside #merchantInfoFeature_feature_div) as the primary signal, with the seller name as a fallback.
  Neither feature reads price/history nor transmits anything externally; nothing read is transmitted off-device.

  *://*.instagram.com/*:
  Required for the Instagram cleaner (11 sub-features). Hides / adds Reels / Explore / Stories tray / Threads promotion / vanity counts / video playback / comment list / Notes / message counters / image download button using semantic selectors based on aria-label / href / role / data-pagelet / SVG path data. URL redirects (e.g. /reels/, /explore/) are also opt-in. Image download issues an image GET only at the moment the user clicks, and only against official CDNs (*.cdninstagram.com / scontent-*.fna.fbcdn.net), with credentials:omit + redirect:manual blocking third-party transmission. Nothing read is transmitted off-device.

  *://*.tiktok.com/*:
  Required for the TikTok cleaner (3 sub-features). Comment list / suggested accounts / image download button are implemented via semantic selectors based on data-e2e and [class*="..."]. For direct photo / video URL access the entire right panel is hidden; in the modal viewer (Browser Mode) only the comment list is hidden. Image download issues an image GET only at the moment the user clicks, and only against official CDNs (*.tiktokcdn.com / *.tiktokcdn-us.com). Nothing read is transmitted off-device.
