【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（30文字以内）
Vuora

■ 概要（132文字以内）
閲覧中ページの見やすさ・聞きやすさ・作業継続性をローカルで整える Chrome 拡張機能。

■ 説明（16,000文字以内）
日々の Web 閲覧を快適にする 13 の機能を、1 つのポップアップにまとめた拡張機能です。カラーピッカー以外の 12 機能はそれぞれ ON/OFF でき、初期状態はすべて OFF です。使いたい機能だけを選んで有効にできます。

■ 主な機能

・📺 YouTube 機能拡張（初期状態 OFF）
  40 のサブ機能を 1 つずつ ON/OFF できます。
  動画フィルタ: プレイリスト / ミックス / Shorts 動画 / Shorts 棚 / ライブ・プレミア・ステーション /メンバー限定 / 視聴済み動画 / ホームのおすすめセクションを非表示。登録したチャンネルの動画を YouTube 全体から除くチャンネルブロックリスト、登録チャンネルの「関連が強い」の非表示、自分の国以外のチャンネルの動画を除く海外チャンネル除外。
  検索結果: 動画棚・カードリスト・コース・チャンネル紹介・Shorts 横棚・関連検索・Shorts フィルタチップなどの非表示、認証チャンネル／アーティストチャンネル／チャプター付き動画の非表示、検索語を含まない動画のグレー表示、サムネイルの枠線表示、検索結果のグリッド表示。
  動画ページ: コメント欄・ライブチャット欄の非表示、ライブ配信アーカイブに実際の配信時刻を表示、ライブ遅延軽減（遅れたときの追いつき方とライブ指標の表示を設定）、画質・再生速度（0.25〜2 倍）・プレイヤー音量の切替、Shorts の URL を通常の再生ページへリダイレクト。Part10 → Part1 のように逆向きに登録された再生リストを、再生リスト欄の「逆順」ボタンで最後の動画から順に再生（次へ・前へ・自動再生も逆向き）。配信者が画面の一部にゲーム映像を置いている配信で、ドラッグで囲んだゲーム画面だけをプレイヤー全体に拡大（範囲はチャンネルごとに端末内へ保存）。
  メニュー / レイアウト: Shorts のサイドバー項目の非表示、登録チャンネルを左メニューに全件表示、「すべての登録チャンネル」へのショートカット、登録チャンネル一覧のグリッド化（チャンネル名・ハンドルで検索）、ホームやフィードのグリッド整列（列数を選択可）。
  外部サービス連携: 視聴中の動画・検索結果・プレイリスト・チャンネルの動画を、自分の Google アカウントの Gemini Notebook にソースとして追加。
  画質・再生速度・音量・ライブ指標・ゲーム画面拡大・配信時刻は操作バーのすぐ上に小さなチップとして 1 行に並び、動画を大きく覆いません。その他の設定は歯車ボタンから開くパネルで、再生中に変更できます。画質・再生速度・音量の切替には、ブラウザの拡張機能ショートカット設定からキーを割り当てられます。

・🐦 X クリーナー（初期状態 OFF）
  X（旧 Twitter）の気が散る表示を整理する 10 のサブ機能です。
  レイアウト: 右ペイン（消した分タイムラインを広げます）/ トレンド / おすすめユーザー / 右下のメッセージドックを非表示
  ノイズ除去: プロモーション投稿 / プレミアムの勧誘 / Grok / 反応数（返信・リポスト・いいね・表示回数）を非表示
  タイムライン: ホームを「フォロー中」タブで開く
  追加機能: 投稿画像にマウスを乗せると保存ボタンを表示し、オリジナル画質で保存

・📷 Instagram クリーナー（初期状態 OFF）
  12 のサブ機能で、冗長な表示の整理と動画操作の追加を行います。
  主要機能: Reels の削除（URL のリダイレクトを含む）/ Explore の削除 / ホームのストーリー段を非表示 / ストーリーの URL をホームへ戻す / Threads への誘導を非表示
  追加機能: いいね数・フォロワー数の非表示 / 投稿内の動画の自動再生を防止 / コメント欄の非表示 / Notes の非表示 / 新規メッセージ数の非表示 / 動画にシークバーを表示（有効時はスペースキーで再生・一時停止）/ 投稿写真に保存ボタンを表示

・🎵 TikTok クリーナー（初期状態 OFF）
  コメント欄の非表示 / おすすめのアカウントの非表示 / 投稿画像に保存ボタンを表示、の 3 つのサブ機能です。

・📖 Wikipedia 閲覧調整（初期状態 OFF）
  Wikipedia の記事を検索・目次・本文・基本情報を中心とした読みやすいレイアウトに組み直し、配色、本文と見出しの書体、文字サイズ、行間、記事の幅、リンクの表示、記事の表示範囲（すべて／本文と画像／本文のみ）を調整できます。日本語フォント 7 書体を同梱しており、外部からフォントを取得しません。
  サブ機能: 新しい記事レイアウト / 固定目次 / 画像の拡大 / リンク・脚注のプレビュー / 「表示」パネルの非表示 / 本文を指定幅に収める
  記事本文・編集への導線・帰属表示はそのまま残り、外部サイトへの転送や独自の記事取得は行いません。OFF にすると元のページ構成に戻ります。

・📦 Amazon 定期おトク便 月別合計（初期状態 OFF）
  amazon.co.jp の定期おトク便の管理画面に、配送月ごとの合計金額（単価×数量）を表示します。一覧に価格がない商品は Amazon から現在の定期便価格を取得し、取得できない場合は前回の配送単価で参考合計を出します。請求額は変わる可能性があり、クーポンは反映しません。全商品の金額がそろわないときは、一部だけの合計は表示しません。

・🏆 Amazon ランキングへ移動ボタン（初期状態 OFF）
  商品ページごとに位置がばらばらな「売れ筋ランキング」のリンクを、商品情報の最上部に 1 つのボタンとしてまとめます。押すと、その商品が属する一番細かいサブカテゴリのランキングへ移動します。

・📦 Amazon 販売元・出荷元バッジ（初期状態 OFF）
  商品ページから販売元と出荷元を読み取り、商品情報の最上部に「販売: ○○ / 出荷: ○○」のバッジで表示します。Amazon 直販は緑、マーケットプレイス出品はオレンジで色分けするため、購入前に出品者を確認しやすくなります。

・🔊 音量ブースター（初期状態 OFF）
  タブの音量を 0〜300% で調整します。ポップアップを開いたタブに適用され、すでにブースト中のタブにはタブを切り替えても自動で再適用されます。サイトの種類を問わず利用できます。
  ・自動歪み防止: 突然の大きな音のピークを抑え、ブースト時の音割れを軽減
  ・ナイトモード: 大きな声や爆発音をなだらかに抑え、小さな音との差を縮める
  ・壁ドン対策モード: 壁や床に響く低音をカット
  ・10 バンドイコライザ: 32 Hz〜16 kHz の各帯域を ±12 dB で調整。プリアンプとプリセット 9 種付き（手動で調整すると「カスタム」に切替）
  ・ミュートボタン: 設定を保ったまま 1 クリックで消音・復帰
  音量 100% でもこれらのサブ機能だけを使えます。不要になったときは音声処理をすぐ解放します。

・🎞️ 動画ガンマ補正（初期状態 OFF）
  ページ上の動画にガンマ補正をかけます。スライダーの中央（1.0）が補正なしで、右に動かすと暗い部分を持ち上げて明るく、左に動かすとコントラストを上げて暗くします（0.3〜3.0）。埋め込み動画を含む全タブ共通の設定です。

・🖥️ 動画の黒帯除去（初期状態 OFF）
  ウルトラワイドモニターなどで動画の上下・左右に出る黒帯を、ズーム（縦横比を保って拡大）または引き伸ばしで除去し、画面いっぱいに表示します。お使いのモニターの縦横比か解像度を選ぶと、動画ごとの形は自動で判別します。

・🔍 ルーペ（初期状態 OFF）
  マウスカーソルに付いて動く円形の拡大鏡です。現在の表示を静止画として取り込んで拡大するので、一時停止した動画の細部も確認できます。倍率は 1.5 / 2.5 / 4 倍、レンズの直径は 150〜1000 px で調整できます。画面を左クリックすると OFF になります。

・🎨 カラーピッカー（常時利用可）
  スポイトで画面上の色を採取し、HEX / RGB / HSL のいずれかでクリップボードにコピーします。色コードを貼り付けて登録することもできます。採取した色は最大 20 件まで履歴として端末内に保存されます。

■ 使い方

1. ツールバーのアイコンをクリックしてポップアップを開く
2. 上部のカテゴリ選択から目的の画面を選ぶ
3. 各機能のスイッチ・スライダー・選択欄で設定する（変更は自動で保存され、すぐ反映されます）

音量ブースター・動画ガンマ補正・動画の黒帯除去・ルーペ・Amazon の 3 機能は「調整」にあります。最後に開いた画面は次回も保持されます。

■ 設定の保存と読み込み
「設定」では、ブラウザの同期機能を使った複数 PC 間の設定同期と、JSON ファイルへのエクスポート・インポートができます。全機能の設定・イコライザ・除外チャンネル・採色履歴・表示中の画面を保存し、別の PC や Chrome／Firefox の間で移せます。同期の ON/OFF、Gemini Notebook の送信先アカウント、認証情報、キャッシュ、ページ上の表示位置は端末ごとに保持します。表示は 9 言語（日本語・英語・中国語〈簡体字・繁体字〉・韓国語・スペイン語・フランス語・ドイツ語・ポルトガル語〈ブラジル〉）に対応し、ブラウザの言語に合わせて切り替わるほか、ポップアップのタイトル横で選ぶこともできます。ライト・ダークにも対応しています。

■ プライバシー

・設定は通常、お使いの端末内に保存されます。任意の設定同期を ON にした場合だけ、対象の設定をブラウザの同期サービスで共有します。ゲーム画面拡大の範囲と、選んだ表示言語は端末内にだけ保存し、同期しません
・閲覧中のページの内容やタブの音声を、広告・解析・テレメトリの目的で収集・送信しません。音量ブースターは音声を増幅して再生するだけで、録音・保存・送信はしません
・外部との通信は、利用者が操作または有効にした次の機能に必要なものだけです
  - Instagram / TikTok / X の画像保存: 保存ボタンを押したときだけ、各サービスの画像配信サーバーから画像を取得します（Cookie・リファラは送りません）
  - YouTube 機能拡張: 海外チャンネル除外・登録チャンネルの全件表示とグリッド化・配信時刻表示が ON のときだけ、YouTube 上のチャンネル概要・登録チャンネル一覧・動画ページなどと、サムネイル画像を取得します
  - Gemini Notebook 送信: サブ機能を ON にして送信パネルを使ったときだけ、ログイン中の Google アカウントで Gemini Notebook と通信し、送信先の確認と動画などの URL の追加を行います
  - Amazon 定期おトク便 月別合計: ON のときだけ、amazon.co.jp から価格を読み取ります。注文や配送は変更せず、結果はページ内だけに保持します
  - 設定同期: ON にした場合のみ、ブラウザの同期サービスを使います
  - お問い合わせ: 利用者がフォームを送信したときだけ、入力内容を Kagayoi Support へ送ります
・開発者のサーバーへ閲覧データを送ることはありません

【プライバシーへの取り組み】タブ

■ このアイテムに単一の目的はありますか？
はい

■ 単一の目的の説明
閲覧中ページの見やすさ・聞きやすさ・作業のしやすさを、利用者が選んだ設定に従って整える。

■ データの使用に関する開示

  ・収集するデータの種類（チェックを入れるもの）:
    - 個人を特定できる情報
    - 認証に関する情報
    - 個人的コミュニケーション
        お問い合わせフォームを利用者が送信した場合に限り、入力されたメールアドレス・任意の名前・件名・本文・メール確認コードを Kagayoi Support で扱います。閲覧内容を開発者のサーバーへ送ることはありません。

  ・収集しないデータの種類:
    健康に関する情報、財務状況や支払いに関する情報、位置情報、ウェブ履歴、ユーザーのアクティビティ、ウェブサイトのコンテンツ

  ・ユーザーのデータをどのように扱いますか？（3 つともチェック）
    - ユーザーデータの販売: しない（承認されている以外の用途で第三者にユーザーデータを販売、転送しません）
    - ユーザーデータの本来の目的以外への使用や転送: しない（アイテムの唯一の目的と関係のない目的でユーザーデータを使用または転送しません）
    - 信用力の判定や貸付目的での使用や転送: しない（信用力を判断する目的または融資目的でユーザーデータを使用または転送しません）

■ 権限の正当性

  activeTab:
  ポップアップから現在のタブに設定を反映し、音量ブースター対象タブの判定に使うため。

  storage:
  機能のオン・オフ、スライダー設定、カラーピッカーの履歴を端末内（chrome.storage.local）に保存するため。任意の「複数PC間で設定を同期」をオンにした場合だけ、対象の設定を chrome.storage.sync にも保存します。カラーピッカーの履歴と認証情報は同期しません。

  offscreen:
  音量ブースターの音声処理（AudioContext による増幅・10 バンドイコライザ・圧縮）を、Service Worker の外で維持するため。tabCapture で取得したタブ音声をこのオフスクリーン ドキュメント内で処理して再出力するだけで、録音・保存・外部送信は行いません。

  tabCapture:
  音量ブースターで、ポップアップを操作したアクティブタブの音声を取得し、増幅・10 バンドイコライザ・圧縮をかけて再出力するため。利用者の操作を起点にそのタブだけを対象とし、音声の録音・保存・外部送信は行いません。

■ ホスト権限の正当性

  全サイトの動画に効く機能（動画ガンマ補正・黒帯除去・ルーペ）のため、すべての http(s) ページにコンテンツスクリプトを入れます。ルーペはオンの間だけ、表示中タブの見えている範囲を静止画で取得して拡大表示します（保存・外部送信なし）。このほか YouTube・Amazon.co.jp・Instagram・TikTok・X・Wikipedia では、各サイト向けの表示調整を行います。利用者が有効にした場合だけ、Gemini Notebook（notebooklm.google.com）へ選んだ YouTube 動画の URL を送り、利用者が送信したお問い合わせを support.kagayoi.com へ送ります。閲覧内容を開発者のサーバーへ送ることはありません。

■ リモートコードを使用していますか？
いいえ
（すべてのコードは拡張機能パッケージ内に含まれており、外部からのコード読み込みは一切行いません。）
