【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（30文字以内）
Vuora

■ 概要（132文字以内）
閲覧中ページの見やすさ・聞きやすさ・作業継続性をローカルで整える Chrome 拡張機能。

■ 説明（16,000文字以内）
日々の Web 閲覧を快適にする 12 カテゴリの補助機能 + 共通サブ機能（Instagram / TikTok の画像ダウンロードボタン）を 1 つのポップアップに統合した拡張機能です。
（v1.0.18 でかつての「制限解除」機能は廃止し、Web 閲覧支援機能のみに特化しました）

■ 主な機能

・📺 YouTube 整理（オプトイン・デフォルトOFF）
  サイドバー / 棚 / 検索結果から Shorts を非表示・物理削除し、`/shorts/<id>` の URL を `/watch?v=<id>` にリダイレクト。
  さらに YouTube 機能拡張として 34 機能（検索結果ノイズ除去 / 動画属性で削除 / ハイライト / 動画ページレイアウト〈コメント欄非表示・ライブチャット非表示〉/ グリッド列数 / ホーム・フィードのグリッド整列 / 登録チャンネル拡張 / ライブ配信の接続モニター）を細かく設定できます。

・🐦 X クリーナー（オプトイン・デフォルトOFF）
  X（旧 Twitter）の気が散る UI を一括非表示にする 9 個のサブ機能を提供します。
  レイアウト: 右ペイン非表示（空いたぶんタイムラインを右端まで拡幅）/ トレンド非表示 / おすすめユーザー非表示 / メッセージドック非表示
  ノイズ除去: プロモーション投稿非表示 / プレミアム勧誘非表示 / Grok 非表示 / 反応数（返信・リポスト・いいね・表示回数）非表示
  タイムライン: ホームを「フォロー中」タブで開く
  ※ セレクタは data-testid ベースの構造マッチのみで、表示言語に依存しません。
  ※ クライアント側の DOM 操作・CSS 適用のみで、外部送信は一切行いません。

・📦 Amazon 定期おトク便 月別合計（オプトイン・デフォルトOFF）
  https://www.amazon.co.jp/auto-deliveries ページで配送月ごとの合計金額を表示します。

・🏆 Amazon ランキングへ移動ボタン（オプトイン・デフォルトOFF）
  Amazon 商品ページの商品詳細欄にある「Amazon 売れ筋ランキング」リンクは商品ごとに位置がバラバラで探しにくいので、商品情報の最上部に「この商品が所属するランキングへ移動」ボタンを集約表示します。クリックで一番細かいサブカテゴリのランキングへ同じタブで移動します。商品詳細コンテナ内の売れ筋ランキングリンクのみを走査するため、ランキングを持つ商品ページでのみボタンが出ます。
  ※ 純粋な DOM 操作のみで、価格・履歴の取得や外部送信は一切行いません。

・📦 Amazon 販売元・出荷元バッジ（オプトイン・デフォルトOFF）
  Amazon 商品ページの隠し div (#merchantInfoFeature_feature_div / #fulfillerInfoFeature_feature_div) から販売元と出荷元を抽出し、商品情報の最上部 (ランキング移動ボタンの隣) に「📦 販売: XXX / 出荷: YYY」のクリック不可の情報バッジを表示します。Amazon 直販と マーケット出品 を視覚的に区別（Amazon 直販 = 緑バッジ / マーケット出品 = オレンジ警告バッジ）。詐欺マーケットプレイス出品の回避や Amazon 直販の確認が一目でできます。直販判定は Amazon 自身が出す isInternal フラグ（#merchantInfoFeature_feature_div 内 <script> 埋め込み JSON）を最優先とし、欠落時は販売元名で推定します。
  ※ 純粋な DOM 操作のみで、価格・履歴の取得や外部送信は一切行いません。

・📷 Instagram クリーナー（オプトイン・デフォルトOFF）
  Instagram の冗長 UI を一括非表示にする 11 個のサブ機能を提供します。
  主要機能: Reels 削除（URL リダイレクト含む）/ Explore 削除 / ストーリー段非表示 / Stories URL ホーム遷移 / Threads 誘導非表示
  追加機能: いいね数・フォロワー数非表示 / 投稿内動画ブロック / コメント欄非表示 / Notes 非表示 / 新規メッセージカウンター非表示 / 画像ダウンロードボタン
  ※ クライアント側の DOM 操作・CSS 適用のみで、外部送信は一切行いません。

・🎵 TikTok クリーナー（オプトイン・デフォルトOFF）
  TikTok の冗長 UI を一括非表示にする 3 個のサブ機能を提供します。
  主要機能: コメント欄非表示 / おすすめのアカウント非表示 / 画像ダウンロードボタン
  ※ photo / video の直接 URL アクセス時は右パネル全体非表示、modal viewer (Browser Mode) ではコメントリストのみピンポイント非表示でプロフィールを温存します。
  ※ クライアント側の DOM 操作・CSS 適用のみで、外部送信は一切行いません。

・🔊 音量ブースター（オプトイン・デフォルトOFF）
  アクティブタブの音量を 0〜300% で増幅。マスタートグルを ON にするとスライダーが有効化され、設定（gain 値・サブトグル・ミュート・イコライザ）はグローバル永続化されます。chrome.tabCapture + オフスクリーン ドキュメント経路で、URL に依らず全サイト一律（Netflix / Prime Video 等の EME 保護動画も含む）に対応します。popup を開いた瞬間にアクティブタブで boost 開始します（chrome.tabCapture は user gesture が必須なので popup を開く操作がゲスチャを兼ねます）。「プリアンプ GainNode → 10 バンド peaking BiquadFilterNode → ナイトモード圧縮（DynamicsCompressor）→ 手動 GainNode で増幅 → 壁ドン対策（highpass BiquadFilterNode で低音カット）→ 自動歪み防止 / リミッタ（DynamicsCompressor）」のチェーンで処理して再出力します（EQ → コンプ → メイクアップゲイン → 低音カット → リミッタ、マスタリング順配置）。自動歪み防止 / ナイトモード / 壁ドン対策モード / イコライザのサブ機能はいずれもデフォルト OFF。
  スライダーは 100..300% 区間で等距離 = 等 dB ステップの対数マッピングを採用、gain 変更は 45ms ramp で滑らかに反映してプチノイズを抑えます。スライダーの左端にミュート 🔊/🔇 ボタンを配置し、スライダー値・サブトグル設定を保持したまま 1 クリックで完全消音 → 再クリックで元の音量に高速復帰できます（Chrome 標準のタブミュートとは独立レイヤとして動作）。10 バンドグラフィックイコライザは 32 / 64 / 125 / 250 / 500 / 1K / 2K / 4K / 8K / 16K Hz の各バンドを ±12dB で調整可能、プリアンプ (全体 ±12dB) と「フラット / 低音強調 / 高音強調 / ボーカル / ラウドネス / カスタム」のプリセット付き（手動操作で自動的に「カスタム」に切替）。スライダー 100% でも自動歪み防止 / ナイトモード / 壁ドン対策モード / ミュート / イコライザのいずれかが ON なら AudioContext を維持し、「音量を変えずに突発音だけ抑える」「夜間に大音量シーンを抑える」「低音だけカットして壁ドンを防ぐ」「100% のまま即消音」「100% で EQ だけかける」用途にも対応。タブ切替時は既に boost 中のタブのみ自動再適用され、新規タブは popup を開いて操作した時点で適用されます。
  ※ マスタートグル OFF / スライダー 100% かつ全サブトグル OFF かつミュート OFF かつ EQ OFF / タブを閉じる / 拡張機能を無効化 のいずれかで AudioContext を即座に解放してリソースを返却します。
  ※ 録音・保存・外部送信は一切行いません。

・🎞️ 動画ガンマ補正（オプトイン・デフォルトOFF）
  ページ上の <video> 要素に SVG <feComponentTransfer type="gamma"> ベースのガンマ補正を適用します。マスタートグル + スライダー構成で、スライダー中央 (1.0) が補正なし、左で暗く（最大 3.0）、右で明るく（最小 0.3）。全タブ共通設定で、iframe 内の <video>（YouTube 埋め込み等）にも all_frames: true で同じ補正が当たります。
  ※ 動画データの読み取り・録画・外部送信は一切行わず、SVG filter を当てるだけのクライアントサイド処理です。

・🖥️ 動画の黒帯除去（オプトイン・デフォルトOFF）
  ウルトラワイドモニターなどで動画の上下/左右に出る黒帯（レターボックス / ピラーボックス）を、ズーム（アスペクト維持で拡大クロップ）または引き伸ばし（不足軸のみ拡大）で除去して画面いっぱいに表示します。マスタートグル + 表示モード選択 + 目標モニターのプリセット構成で、動画側の縦横比は videoWidth / videoHeight から自動検出します。全タブ共通設定で、iframe 内の <video> にも all_frames: true で同じ処理が当たります。
  ※ 動画データの読み取り・録画・外部送信は一切行わず、CSS transform を当てるだけのクライアントサイド処理です。

・🔍 ルーペ（オプトイン・デフォルトOFF）
  マウスカーソルに追従する円形拡大鏡。マスタートグルを ON にすると、現在のタブを chrome.tabs.captureVisibleTab で JPEG 静止画として取得し、円形レンズ (position: fixed + clip-path: circle()) に background-image として貼り付け、mousemove から background-position を rAF コアレス 60fps で更新してカーソル下の領域を拡大表示します。動画 / iframe / canvas を含む描画ピクセルがそのまま映るため「動画を一時停止して細部を確認」する用途に最適です。倍率はポップアップのセグメントコントロールで 1.5× / 2.5× / 4× の 3 段階から選択、レンズサイズはスライダーで 150〜1000px の範囲で可変。画面上で左クリックすると即座にレンズが撤去されマスタートグルも OFF に書き戻ります。再キャプチャは初回 / スクロール (500ms debounced) / DOM 大幅変化 (MutationObserver) / ウィンドウリサイズ で自動的に発火します。
  ※ 取得した JPEG は Blob URL に変換して content script の DOM 上で参照され、OFF 時に URL.revokeObjectURL で確実に解放されます。録画・保存・外部送信は一切行いません。

・🎨 カラーピッカー（常時利用可）
  ポップアップの「カラーピッカー」タブから EyeDropper API で画面上の色を採取し、HEX / RGB / HSL の 3 形式でクリップボードにコピーできます。HEX に「#」を含めるか個別に切替可能。採取した色は最大 20 件の標本箱（履歴）として端末内にのみ保存されます。
  ※ 録音・保存・外部送信は一切行わず、すべての処理は popup 内で完結します。

■ 使い方

1. ツールバーのアイコンをクリックしてポップアップを開く
2. ポップアップ上部のタブ（調整 / YouTube / Instagram / TikTok / カラーピッカー）から目的の機能を選ぶ
3. 各タブ内のトグル・スライダーで ON/OFF と値を即時調整（自動保存）
4. 音量ブースター・動画ガンマ補正はスライダーで直接調整
5. 「カラーピッカー」タブで EyeDropper を起動して画面上の色を採取

設定は自動保存され、次回起動時も同じ状態が復元されます。

■ プライバシー

・設定は通常、お使いの端末内（chrome.storage.local）に保存されます。任意のPC間同期をONにすると、対象設定をブラウザの同期サービスで共有します
・閲覧ページの内容やタブ音声を、広告・解析・テレメトリ目的で収集または送信しません
・利用者が任意のお問い合わせフォームを送信したときだけ、入力したメールアドレス・任意のお名前・問い合わせ内容・確認コード等を Kagayoi Support へ送信します
・このほかの外部通信は、利用者が操作または有効化した Instagram / TikTok の画像取得、YouTube ライブ接続モニター、Gemini Notebook への動画 URL 送信、ブラウザ標準の設定同期に限られます
  （Instagram / TikTok の画像ダウンロードボタン ON 時、ユーザーがボタンをクリックした瞬間のみ各サイトの正規 CDN（*.cdninstagram.com / scontent-*.fna.fbcdn.net / *.tiktokcdn.com / *.tiktokcdn-us.com）に画像 GET を発行します。credentials:omit + redirect:manual + referrerPolicy:no-referrer でクロスオリジン認証情報送信を遮断し、それ以外のオリジンへの代理 fetch はホスト名ホワイトリストで遮断します）
・音量ブースター利用時のタブ音声データは AudioContext で増幅・再出力するのみで、録音・保存・外部送信は行いません

■ 権限の正当性（簡潔版・40〜60 文字目安）

  activeTab:
  ポップアップから現在のタブに設定を反映し、音量ブースター対象タブの判定に使うため。

  storage:
  機能トグル・スライダー設定・カラーピッカー履歴を端末内 (chrome.storage.local) に保存し、任意のPC間同期をONにした場合は対象設定を storage.sync へ保存するため。採色履歴と認証情報は同期対象外です。

  offscreen:
  音量ブースターの AudioContext / GainNode / BiquadFilterNode / DynamicsCompressor チェーンを Service Worker 外で維持するため。tabCapture で取得したタブ音声をこの offscreen document の AudioContext に流し込み、0〜300% の増幅・10 バンド EQ・圧縮を行います。

  tabCapture:
  音量ブースターでタブ音声を取得し、AudioContext で 0〜300% の増幅・10 バンド EQ・圧縮を行うため。popup を開いて操作したアクティブタブのみが対象で（user gesture 必須）、URL に依らず全サイト一律（Netflix / Prime Video 等の EME 保護動画も含む）で動作します。

  <all_urls> (host permission):
  ルーペ機能で chrome.tabs.captureVisibleTab によりアクティブタブの可視領域を JPEG 静止画として取得し、円形レンズに拡大表示するため。activeTab 権限のみだと popup close 後や SPA 内 navigation で grant が早期失効するためルーペが動作しなくなる事例があり、確実な動作のため追加。content_scripts で既に全 http(s) に注入済みでアクセス可能範囲は実質変わらない。

■ ホスト権限の正当性

  http://*/* および https://*/*:
  動画ガンマ補正・動画の黒帯除去・ルーペの 3 機能のため、全 http(s) サイトに content script を注入する必要がある。
  (1) 動画ガンマ補正: マスタートグル ON 時のみ <video> 要素に SVG filter (url(#__cpa-video-gamma)) を当てる CSS と SVG <feComponentTransfer type="gamma"> 定義を <body> に注入する。全タブ + 全フレーム (iframe 内 <video> 含む) に適用するため http://*/* + https://*/* + all_frames: true の content script として動作する。
  (2) 動画の黒帯除去: マスタートグル ON 時のみ <video> の縦横比を検出し、CSS transform で上下/左右の黒帯を除去する（全フレーム対象、元の inline transform は撤去時に復元）。
  (3) ルーペ: マスタートグル ON 時のみマウス追従の円形拡大鏡を表示する（拡大画像そのものは下記 <all_urls> の captureVisibleTab で取得）。
  いずれもページ DOM の読み取り・書き換え・外部送信は一切行わない（ガンマ補正・黒帯除去は <video> へのフィルタ / transform 適用のみで、動画データの読み取りや保存は行わない）。

  *://*.youtube.com/*:
  YouTube 機能拡張（34 サブ機能・Shorts 削除・登録チャンネル拡張・接続モニターを含む）のため。検索結果ノイズ除去・動画ページ装飾（コメント欄非表示 / ライブチャット折りたたみ）・ホームグリッド列数調整・/shorts/<id> → /watch?v=<id> リダイレクト・/feed/channels グリッド化を DOM/CSS 操作のみで実装。読み取り情報は端末外へ送信しない。

  *://www.amazon.co.jp/auto-deliveries*:
  Amazon 定期おトク便の月別合計表示のため。配送月ごとの subscription-price を読み取って合計値を計算し、同ページに挿入する。読み取り情報は端末外へ送信しない。

  *://www.amazon.co.jp/*:
  Amazon ランキングへ移動ボタン + Amazon 販売元・出荷元バッジのため。
  (1) ランキング移動ボタン: 商品詳細コンテナ内の「Amazon 売れ筋ランキング」リンク (a[href*="bestsellers/"]) のみを走査し、一番細かいサブカテゴリへのリンクを商品情報最上部の集約ボタンとして挿入する。商品ページでのみボタンが出る自己ゲート方式。
  (2) 販売元・出荷元バッジ: 商品ページの #merchantInfoFeature_feature_div / #fulfillerInfoFeature_feature_div 隠し div から販売元・出荷元を抽出して、商品情報最上部にバッジ表示する（Amazon 直販 = 緑バッジ / マーケット出品 = オレンジ警告バッジ）。Amazon 直販判定は #merchantInfoFeature_feature_div 内 <script> 埋め込み JSON の isInternal フラグを最優先とし、欠落時は販売元名で推定。
  どちらも価格・履歴の取得や外部送信は一切行わず、読み取り情報は端末外へ送信しない。

  *://*.instagram.com/*:
  Instagram クリーナー（11 サブ機能）のため。Reels / Explore / ストーリー段 / Threads 誘導 / いいね数・フォロワー数 / 動画再生 / コメント欄 / Notes / メッセージカウンター / 画像ダウンロードボタンの非表示・追加を、aria-label / href / role / data-pagelet / SVG path data ベースの意味論的セレクタで実装。/reels/ / /explore/ 等の URL リダイレクトもオプトイン。画像ダウンロードはユーザーがクリックした瞬間に正規 CDN（*.cdninstagram.com / scontent-*.fna.fbcdn.net）への画像 GET のみ発行し、credentials:omit + redirect:manual で第三者送信を遮断。読み取り情報は端末外へ送信しない。

  *://*.tiktok.com/*:
  TikTok クリーナー（3 サブ機能）のため。コメント欄 / おすすめのアカウント / 画像ダウンロードボタンを、data-e2e / [class*="..."] ベースの意味論的セレクタで実装。photo / video の直接 URL アクセス時は右パネル全体を非表示、modal viewer (Browser Mode) ではコメントリストのみピンポイント非表示。画像ダウンロードはユーザーがクリックした瞬間に正規 CDN（*.tiktokcdn.com / *.tiktokcdn-us.com）への画像 GET のみ発行する。読み取り情報は端末外へ送信しない。

  *://x.com/*, *://twitter.com/*:
  X クリーナー（9 サブ機能）のため。右ペイン / トレンド / おすすめユーザー / メッセージドック / プロモーション投稿 / プレミアム勧誘 / Grok / 反応数の非表示と、ホームの「フォロー中」タブ選択を、data-testid ベースの構造セレクタ（:has()）で実装。読み取り情報は端末外へ送信しない。
