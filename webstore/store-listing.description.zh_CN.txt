Vuora 将 13 项日常浏览辅助功能整合在一个弹出窗口中。除取色器外，其余 12 项功能均可单独开启或关闭，初始状态全部为关闭，只有您选择启用的功能才会作用于网页。

■ 主要功能

・📺 YouTube 增强（初始状态关闭）
  40 个子功能，可逐项开启或关闭。
  视频过滤：隐藏播放列表 / 合辑 / Shorts 视频 / Shorts 栏目 / 直播、首映、电台 / 会员专享 / 已观看视频 / 首页的推荐栏目。可使用频道屏蔽列表，将所选频道的视频从整个 YouTube 中移除；还可隐藏订阅中的“相关度高”，并排除来自您所在国家以外频道的视频。
  搜索结果：隐藏视频栏目、卡片列表、课程、频道介绍、Shorts 横向栏目、相关搜索和 Shorts 筛选标签等；隐藏认证频道、艺人频道和带章节的视频；将不含搜索词的视频显示为灰色；为缩略图添加边框；以网格显示搜索结果。
  观看页：隐藏评论区和直播聊天区，在直播回放中显示实际播出时间，直播延迟控制（可设置落后时的追赶方式和直播指标的显示），切换画质、播放速度（0.25 至 2 倍）和播放器音量，并将 Shorts 的网址重定向到普通播放页。对于按 Part10 → Part1 这样倒序登记的播放列表，可通过播放列表栏的“逆序”按钮从最后一个视频开始依次播放（下一个、上一个和自动播放也按逆序进行）。对于主播把游戏画面放在画面一角的直播，只需拖动框选游戏画面，即可将播放器整体放大到该区域（范围按频道保存在本机）。
  菜单 / 布局：隐藏 Shorts 侧边栏项目，在左侧菜单中显示全部订阅频道，提供“全部订阅频道”的快捷入口，将订阅频道列表改为网格（可按频道名称和用户名搜索），并以网格排列首页和订阅动态（可选择列数）。
  外部服务集成：将正在观看的视频、搜索结果、播放列表和频道中的视频，作为来源添加到您自己 Google 账号的 Gemini Notebook。
  画质、播放速度、音量、直播指标、游戏画面放大和播出时间，会以小标签的形式排成一行，显示在控制栏的正上方，不会大面积遮挡视频。其他设置可在点击齿轮按钮打开的面板中，于播放过程中更改。画质、播放速度和音量的切换，可在浏览器的扩展程序快捷键设置中分配按键。

・🐦 X 清理器（初始状态关闭）
  整理 X（原 Twitter）中分散注意力的显示内容，共 10 个子功能。
  布局：隐藏右侧窗格（时间线会相应变宽）/ 趋势 / 推荐关注 / 右下角的消息悬浮栏
  干扰：隐藏推广帖子 / Premium 订阅推广 / Grok / 互动数（回复、转发、点赞、查看次数）
  时间线：主页默认打开“正在关注”标签
  附加：将鼠标移到帖子图片上时显示保存按钮，以原始画质保存

・📷 Instagram 清理器（初始状态关闭）
  通过 12 个子功能，整理冗余的显示内容并增加视频操作。
  主要：移除 Reels（包括网址重定向）/ 移除 Explore / 隐藏主页的快拍栏 / 将快拍的网址返回主页 / 隐藏对 Threads 的引导
  附加：隐藏点赞数和粉丝数 / 防止帖子内视频自动播放 / 隐藏评论区 / 隐藏 Notes / 隐藏新消息数 / 为视频显示进度条（启用时可按空格键播放和暂停）/ 在帖子照片上显示保存按钮

・🎵 TikTok 清理器（初始状态关闭）
  共 3 个子功能：隐藏评论区 / 隐藏推荐账号 / 在帖子图片上显示保存按钮。

・📖 Wikipedia 阅读设置（初始状态关闭）
  将 Wikipedia 的文章重新排版，以搜索、目录、正文和信息框为中心，使阅读更轻松，并可调整配色、正文与标题的字体、文字大小、行距、文章宽度、链接的显示方式以及文章的显示范围（全部 / 正文和图片 / 仅正文）。内置 7 款日文字体，不会从外部获取字体。
  子功能：新文章布局 / 固定目录 / 图片放大 / 链接和脚注预览 / 隐藏“外观”面板 / 将正文限制在指定宽度内
  文章正文、编辑入口和署名信息均保持原样，不会跳转到外部网站，也不会自行获取文章。关闭后将恢复原来的页面结构。

・📦 Amazon 定期配送每月合计（初始状态关闭）
  在 amazon.co.jp 的定期配送（Subscribe & Save）管理页面中，按配送月份显示合计金额（单价×数量）。列表中没有价格的商品，会从 Amazon 获取当前的定期配送价格；无法获取时，则以上次配送的单价计算参考合计。实际扣款金额可能发生变化，且不包含优惠券。如果无法凑齐全部商品的金额，则不会显示仅含部分商品的合计。

・🏆 Amazon 跳转排名按钮（初始状态关闭）
  各商品页中“热销排行榜”链接的位置各不相同，此功能将其汇总为商品信息最上方的一个按钮。点击后会跳转到该商品所属的最细分子类别的排名。

・📦 Amazon 卖家/发货方标识（初始状态关闭）
  从商品页读取卖家和发货方，并在商品信息最上方以“销售：○○ / 发货：○○”的标识显示。亚马逊自营显示为绿色，第三方卖家显示为橙色，方便您在购买前确认卖家。

・🔊 音量增强器（初始状态关闭）
  可将标签页的音量调节到 0 至 300%。作用于打开弹出窗口的标签页，对已处于增强状态的标签页，切换标签页后会自动重新应用。不限网站类型，均可使用。
  ・自动失真防护：抑制突然出现的大音量峰值，减轻增强时的破音
  ・夜间模式：平缓压低大声说话和爆炸声，缩小与小声之间的差距
  ・防扰邻低音：削减会传到墙壁和地板的低音
  ・10 段均衡器：可在 32 Hz 至 16 kHz 的各频段内以 ±12 dB 调节。附带前置放大和 9 种预设（手动调整后会切换为“自定义”）
  ・静音按钮：保留设置，一键静音和恢复
  即使音量为 100%，也可以只使用这些子功能。不再需要时会立即释放音频处理。

・🎞️ 视频伽马（初始状态关闭）
  对页面上的视频进行伽马校正。滑块的中间位置（1.0）表示不校正，向右拖动会提亮暗部使画面变亮，向左拖动则提高对比度使画面变暗（0.3 至 3.0）。该设置对所有标签页通用，包括嵌入的视频。

・🖥️ 去除视频黑边（初始状态关闭）
  对于超宽显示器等设备上视频四周出现的黑边，可通过缩放（保持宽高比放大）或拉伸将其去除，让视频铺满屏幕。选择您显示器的宽高比或分辨率后，会自动判断每个视频的画面比例。

・🔍 放大镜（初始状态关闭）
  跟随鼠标指针移动的圆形放大镜。它会截取当前显示的画面并放大，因此也可以查看暂停视频中的细节。放大倍率可选 1.5 / 2.5 / 4 倍，镜片直径可在 150 至 1000 px 之间调整。在屏幕上单击左键即可关闭。

・🎨 取色器（始终可用）
  使用吸管吸取屏幕上的颜色，并以 HEX / RGB / HSL 中的任一格式复制到剪贴板。也可以粘贴颜色代码来添加颜色。已吸取的颜色最多可在本机保存 20 条历史记录。

■ 使用方法

1. 点击工具栏中的图标，打开弹出窗口
2. 从顶部的分类选择中选择所需的页面
3. 通过各功能的开关、滑块和选择栏进行设置（更改会自动保存并立即生效）

音量增强器、视频伽马、去除视频黑边、放大镜以及 3 项 Amazon 功能位于“调整”中。下次打开时，会保留上次打开的页面。

■ 设置的保存和读取
在“设置”中，可以利用浏览器的同步功能在多台电脑间同步设置，也可以导出和导入 JSON 文件。会保存全部功能的设置、均衡器、已屏蔽的频道、取色历史和当前显示的页面，可在另一台电脑，或在 Chrome 与 Firefox 之间迁移。同步的开关、Gemini Notebook 的发送账号、认证信息、缓存以及页面上的显示位置，均按设备分别保存。界面支持 9 种语言（日语、英语、中文〈简体、繁体〉、韩语、西班牙语、法语、德语、葡萄牙语〈巴西〉），会根据浏览器的语言自动切换，也可以在弹出窗口标题旁手动选择。同时支持浅色和深色主题。

■ 隐私

・设置通常保存在您的设备中。只有开启可选的设置同步时，才会通过浏览器的同步服务共享相应的设置。游戏画面放大的范围和所选的显示语言只保存在本机，不会同步
・不会以广告、分析或遥测为目的收集或发送您正在浏览的页面内容和标签页的音频。音量增强器只对音频进行增强并播放，不会录制、保存或发送
・对外通信仅限于您操作或启用的以下功能所必需的内容
  - Instagram / TikTok / X 的图片保存：只有在点击保存按钮时，才会从各服务的图片分发服务器获取图片（不发送 Cookie 和引荐来源）
  - YouTube 增强：只有在排除其他国家频道、显示全部订阅频道、订阅频道网格化以及显示播出时间处于开启状态时，才会获取 YouTube 上的频道简介、订阅频道列表、视频页面等内容以及缩略图
  - 发送到 Gemini Notebook：只有在开启该子功能并使用发送面板时，才会使用已登录的 Google 账号与 Gemini Notebook 通信，确认发送目标并添加视频等的网址
  - Amazon 定期配送每月合计：只有在开启时，才会从 amazon.co.jp 读取价格。不会更改订单和配送，结果仅保留在页面内
  - 设置同步：只有在开启时，才会使用浏览器的同步服务
  - 联系我们：只有在您提交表单时，才会将输入的内容发送给 Kagayoi Support
・不会将浏览数据发送到开发者的服务器
