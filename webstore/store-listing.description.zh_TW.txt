Vuora 將 13 項日常瀏覽輔助功能整合在同一個彈出視窗中。除了色彩選擇器之外，其餘 12 項功能都可以個別開啟或關閉，初始狀態全部為關閉，只有您選擇啟用的功能才會作用於網頁。

■ 主要功能

・📺 YouTube 加強功能（初始狀態關閉）
  共 40 個子功能，可逐項開啟或關閉。
  影片篩選：隱藏播放清單 / 合輯 / Shorts 影片 / Shorts 區塊 / 直播、首播、電台 / 會員專屬 / 已觀看的影片 / 首頁的推薦區塊。可使用頻道封鎖清單，將所選頻道的影片從整個 YouTube 中移除；也可隱藏訂閱內容中的「關聯性高」，並排除您所在國家以外的頻道影片。
  搜尋結果：隱藏影片區塊、卡片清單、課程、頻道介紹、Shorts 橫向區塊、相關搜尋與 Shorts 篩選標籤等；隱藏已驗證頻道、藝人頻道與含章節的影片；將不含搜尋字詞的影片以灰色顯示；為縮圖加上框線；以格狀顯示搜尋結果。
  觀看頁面：隱藏留言區與直播聊天室，在直播存檔中顯示實際的播出時間，直播延遲控制（可設定落後時的追趕方式與直播指標的顯示），切換畫質、播放速度（0.25 至 2 倍）與播放器音量，並將 Shorts 的網址重新導向至一般播放頁面。對於以 Part10 → Part1 這種反向順序登錄的播放清單，可透過播放清單欄的「反向」按鈕，從最後一部影片開始依序播放（下一部、上一部與自動播放也會反向進行）。對於實況主把遊戲畫面放在畫面一角的直播，只要拖曳框選遊戲畫面，就能將整個播放器放大至該範圍（範圍會依頻道儲存在本機）。
  選單／版面：隱藏 Shorts 側邊欄項目，在左側選單中顯示全部訂閱頻道，提供「所有訂閱頻道」的捷徑，將訂閱頻道清單改為格狀（可依頻道名稱與帳號代碼搜尋），並以格狀排列首頁與動態消息（可選擇欄數）。
  外部服務整合：將正在觀看的影片、搜尋結果、播放清單與頻道中的影片，作為來源加入您自己 Google 帳戶的 Gemini Notebook。
  畫質、播放速度、音量、直播指標、遊戲畫面放大與播出時間，會以小型標籤排成一行，顯示在控制列的正上方，不會大面積遮住影片。其他設定可在點擊齒輪按鈕開啟的面板中，於播放途中變更。畫質、播放速度與音量的切換，可在瀏覽器的擴充功能快速鍵設定中指派按鍵。

・🐦 X 清理工具（初始狀態關閉）
  整理 X（舊稱 Twitter）中容易分散注意力之顯示內容的 10 個子功能。
  版面：隱藏右側窗格（時間軸會隨之加寬）/ 趨勢 / 推薦追蹤 / 右下角的訊息浮動列
  雜訊：隱藏推廣貼文 / Premium 的訂閱推廣 / Grok / 互動數（回覆、轉發、喜歡、觀看次數）
  時間軸：首頁預設開啟「追蹤中」分頁
  附加：滑鼠移到貼文圖片上時顯示儲存按鈕，以原始畫質儲存

・📷 Instagram 清理工具（初始狀態關閉）
  以 12 個子功能整理多餘的顯示內容，並新增影片操作。
  主要：移除 Reels（包含網址的重新導向）/ 移除 Explore / 隱藏首頁的限時動態列 / 將限時動態的網址導回首頁 / 隱藏對 Threads 的引導
  附加：隱藏喜歡數與追蹤者人數 / 防止貼文內影片自動播放 / 隱藏留言區 / 隱藏 Notes / 隱藏新訊息數 / 為影片顯示進度列（啟用時可按空白鍵播放與暫停）/ 在貼文相片上顯示儲存按鈕

・🎵 TikTok 清理工具（初始狀態關閉）
  共 3 個子功能：隱藏留言區 / 隱藏推薦帳號 / 在貼文圖片上顯示儲存按鈕。

・📖 Wikipedia 閱讀設定（初始狀態關閉）
  將 Wikipedia 的文章重新編排，以搜尋、目錄、內文與資訊框為中心，讓閱讀更輕鬆，並可調整配色、內文與標題的字型、文字大小、行距、文章寬度、連結的顯示方式，以及文章的顯示範圍（全部 / 內文與圖片 / 僅內文）。內建 7 種日文字型，不會從外部取得字型。
  子功能：新文章版面 / 固定目錄 / 圖片放大 / 連結與註腳預覽 / 隱藏「外觀」面板 / 將內文限制在指定寬度內
  文章內文、編輯入口與署名資訊都會維持原樣，不會轉址到外部網站，也不會自行取得文章。關閉後會恢復原本的頁面結構。

・📦 Amazon 定期配送每月合計（初始狀態關閉）
  在 amazon.co.jp 的定期配送（Subscribe & Save）管理頁面中，依配送月份顯示合計金額（單價×數量）。清單中沒有價格的商品，會從 Amazon 取得目前的定期配送價格；無法取得時，則以上次配送的單價計算參考合計。實際請款金額可能會變動，且不包含優惠券。若無法湊齊所有商品的金額，就不會顯示僅含部分商品的合計。

・🏆 Amazon 前往排行榜按鈕（初始狀態關閉）
  各商品頁中「暢銷排行榜」連結的位置各不相同，此功能會將其彙整為商品資訊最上方的一個按鈕。按下後會前往該商品所屬的最細分子類別排行榜。

・📦 Amazon 賣家／出貨方標章（初始狀態關閉）
  從商品頁讀取賣家與出貨方，並在商品資訊最上方以「販售：○○ / 出貨：○○」的標章顯示。Amazon 直售以綠色、市集賣家以橘色區分，方便您在購買前確認賣家。

・🔊 音量增強器（初始狀態關閉）
  可將分頁的音量調整至 0 至 300%。作用於開啟彈出視窗的分頁，對已處於增強狀態的分頁，切換分頁後會自動重新套用。不限網站類型皆可使用。
  ・自動破音防護：抑制突然出現的大音量峰值，減輕增強時的破音
  ・夜間模式：平緩壓低大聲說話與爆炸聲，縮小與小聲之間的落差
  ・防擾鄰低頻抑制：削減會傳到牆壁與地板的低頻
  ・10 段等化器：可在 32 Hz 至 16 kHz 的各頻段以 ±12 dB 調整。附有前級放大與 9 種預設（手動調整後會切換為「自訂」）
  ・靜音按鈕：保留設定，一鍵靜音與還原
  即使音量為 100%，也能只使用這些子功能。不再需要時會立即釋放音訊處理。

・🎞️ 影片 Gamma（初始狀態關閉）
  對頁面上的影片進行 Gamma 校正。滑桿的中央（1.0）表示不校正，向右移動會提亮暗部使畫面變亮，向左移動則提高對比使畫面變暗（0.3 至 3.0）。此設定適用於所有分頁，包含嵌入的影片。

・🖥️ 移除影片黑邊（初始狀態關閉）
  針對超寬螢幕等裝置上影片周圍出現的黑邊，可透過縮放（維持長寬比放大）或拉伸將其移除，讓影片填滿整個畫面。選擇您螢幕的長寬比或解析度後，會自動判斷每部影片的比例。

・🔍 放大鏡（初始狀態關閉）
  跟隨滑鼠游標移動的圓形放大鏡。它會擷取目前顯示的畫面並放大，因此也能查看暫停影片中的細節。放大倍率可選 1.5 / 2.5 / 4 倍，鏡片直徑可在 150 至 1000 px 之間調整。在畫面上按一下左鍵即可關閉。

・🎨 色彩選擇器（隨時可用）
  使用滴管擷取畫面上的顏色，並以 HEX / RGB / HSL 其中一種格式複製到剪貼簿。也可以貼上色碼來新增顏色。已擷取的顏色最多可在本機保留 20 筆記錄。

■ 使用方式

1. 按一下工具列的圖示，開啟彈出視窗
2. 從上方的類別選單選擇需要的畫面
3. 透過各功能的開關、滑桿與選取欄進行設定（變更會自動儲存並立即生效）

音量增強器、影片 Gamma、移除影片黑邊、放大鏡以及 3 項 Amazon 功能位於「調整」中。下次開啟時，會保留上次開啟的畫面。

■ 設定的儲存與載入
在「設定」中，可以利用瀏覽器的同步功能在多部電腦之間同步設定，也可以匯出與匯入 JSON 檔案。會儲存所有功能的設定、等化器、已封鎖的頻道、取色記錄與目前顯示的畫面，可移至另一部電腦，或在 Chrome 與 Firefox 之間移轉。同步的開關、Gemini Notebook 的傳送帳戶、驗證資訊、快取以及頁面上的顯示位置，會依裝置分別保存。介面支援 9 種語言（日文、英文、中文〈簡體、繁體〉、韓文、西班牙文、法文、德文、葡萄牙文〈巴西〉），會依瀏覽器的語言自動切換，也可以在彈出視窗標題旁手動選擇。同時支援淺色與深色主題。

■ 隱私權

・設定通常儲存在您的裝置中。只有開啟選用的設定同步時，才會透過瀏覽器的同步服務共用相應的設定。遊戲畫面放大的範圍與所選的顯示語言只儲存在本機，不會同步
・不會以廣告、分析或遙測為目的蒐集或傳送您正在瀏覽的頁面內容與分頁的音訊。音量增強器只會對音訊進行增強並播放，不會錄製、儲存或傳送
・對外通訊僅限於您操作或啟用的下列功能所必需的內容
  - Instagram / TikTok / X 的圖片儲存：只有在按下儲存按鈕時，才會從各服務的圖片傳送伺服器取得圖片（不傳送 Cookie 與參照來源）
  - YouTube 加強功能：只有在排除其他國家頻道、顯示全部訂閱頻道、訂閱頻道格狀化以及顯示播出時間處於開啟狀態時，才會取得 YouTube 上的頻道簡介、訂閱頻道清單、影片頁面等內容以及縮圖
  - 傳送至 Gemini Notebook：只有在開啟該子功能並使用傳送面板時，才會使用已登入的 Google 帳戶與 Gemini Notebook 通訊，確認傳送目的地並加入影片等的網址
  - Amazon 定期配送每月合計：只有在開啟時，才會從 amazon.co.jp 讀取價格。不會變更訂單與配送，結果僅保留在頁面內
  - 設定同步：只有在開啟時，才會使用瀏覽器的同步服務
  - 聯絡我們：只有在您送出表單時，才會將輸入的內容傳送給 Kagayoi Support
・不會將瀏覽資料傳送到開發者的伺服器
