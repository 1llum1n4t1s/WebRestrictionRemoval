Vuora는 일상적인 웹 브라우징을 편안하게 해 주는 13가지 기능을 하나의 팝업에 모은 확장 프로그램입니다. 컬러 피커를 제외한 12가지 기능은 각각 켜고 끌 수 있으며, 초기 상태는 모두 꺼져 있습니다. 사용하려는 기능만 골라서 켤 수 있습니다.

■ 주요 기능

・📺 YouTube 기능 확장(초기 상태 꺼짐)
  40가지 하위 기능을 하나씩 켜고 끌 수 있습니다.
  영상 필터: 재생목록 / 믹스 / Shorts 영상 / Shorts 선반 / 라이브·프리미어·스테이션 / 멤버 전용 / 시청한 영상 / 홈의 추천 섹션을 숨깁니다. 등록한 채널의 영상을 YouTube 전체에서 제외하는 채널 차단 목록, 구독 피드의 '관련성 높음' 숨기기, 내 국가 밖 채널의 영상을 제외하는 다른 국가 채널 숨기기도 지원합니다.
  검색 결과: 영상 선반, 카드 목록, 강좌, 채널 소개, Shorts 가로 선반, 관련 검색, Shorts 필터 칩 등을 숨기고, 인증 채널 / 아티스트 채널 / 챕터가 있는 영상을 숨기며, 검색어가 포함되지 않은 영상을 회색으로 표시하고, 썸네일에 테두리를 표시하며, 검색 결과를 그리드로 표시합니다.
  동영상 페이지: 댓글란과 라이브 채팅란 숨기기, 라이브 방송 다시보기에 실제 방송 시각 표시, 라이브 지연 제어(뒤처졌을 때 따라잡는 방식과 라이브 지표 표시를 설정), 화질 · 재생 속도(0.25~2배) · 플레이어 볼륨 전환, Shorts URL을 일반 재생 페이지로 리디렉션합니다. Part10 → Part1처럼 거꾸로 등록된 재생목록은 재생목록 패널의 '역순' 버튼으로 마지막 영상부터 차례로 재생할 수 있습니다(다음·이전·자동재생도 역방향으로 동작). 방송자가 화면 일부에 게임 영상을 배치한 방송에서는 드래그로 지정한 게임 화면만 플레이어 전체로 확대합니다(범위는 채널별로 기기 안에 저장).
  메뉴 / 레이아웃: Shorts 사이드바 항목 숨기기, 구독 채널을 왼쪽 메뉴에 모두 표시, '모든 구독'으로 가는 바로가기, 구독 채널 목록의 그리드화(채널 이름·핸들로 검색), 홈과 피드의 그리드 정렬(열 수 선택 가능)을 제공합니다.
  외부 서비스 연동: 시청 중인 영상, 검색 결과, 재생목록, 채널의 영상을 내 Google 계정의 Gemini Notebook에 소스로 추가합니다.
  화질 · 재생 속도 · 볼륨 · 라이브 지표 · 게임 화면 확대 · 방송 시각은 컨트롤 바 바로 위에 작은 칩으로 한 줄에 나란히 표시되어 영상을 크게 가리지 않습니다. 그 밖의 설정은 톱니바퀴 버튼으로 여는 패널에서 재생 중에도 변경할 수 있습니다. 화질 · 재생 속도 · 볼륨 전환에는 브라우저의 확장 프로그램 단축키 설정에서 키를 지정할 수 있습니다.

・🐦 X 클리너(초기 상태 꺼짐)
  X(구 Twitter)에서 주의를 흩뜨리는 표시를 정리하는 10가지 하위 기능입니다.
  레이아웃: 오른쪽 창(숨긴 만큼 타임라인이 넓어집니다) / 트렌드 / 추천 사용자 / 오른쪽 아래 메시지 도크 숨기기
  노이즈: 프로모션 게시물 / 프리미엄 권유 / Grok / 반응 수(답글 · 리포스트 · 좋아요 · 조회수) 숨기기
  타임라인: 홈을 '팔로우 중' 탭으로 열기
  추가 기능: 게시물 이미지에 마우스를 올리면 저장 버튼을 표시하고 원본 화질로 저장

・📷 Instagram 클리너(초기 상태 꺼짐)
  12가지 하위 기능으로 불필요한 표시를 정리하고 동영상 조작을 추가합니다.
  기본: Reels 제거(URL 리디렉션 포함) / Explore 제거 / 홈의 스토리 줄 숨기기 / 스토리 URL을 홈으로 되돌리기 / Threads 유도 숨기기
  추가 기능: 좋아요 수 · 팔로워 수 숨기기 / 게시물 안 동영상의 자동 재생 방지 / 댓글란 숨기기 / Notes 숨기기 / 새 메시지 수 숨기기 / 동영상에 탐색 바 표시(켜져 있으면 스페이스 키로 재생 · 일시정지) / 게시물 사진에 저장 버튼 표시

・🎵 TikTok 클리너(초기 상태 꺼짐)
  댓글란 숨기기 / 추천 계정 숨기기 / 게시물 이미지에 저장 버튼 표시, 이렇게 3가지 하위 기능입니다.

・📖 Wikipedia 읽기 설정(초기 상태 꺼짐)
  Wikipedia 문서를 검색 · 목차 · 본문 · 정보 상자 중심의 읽기 편한 레이아웃으로 다시 구성하고, 색상 구성, 본문과 제목의 글꼴, 글자 크기, 줄 간격, 문서 너비, 링크 표시 방식, 문서 표시 범위(전체 / 본문과 이미지 / 본문만)를 조정할 수 있습니다. 일본어 글꼴 7종을 내장하고 있어 외부에서 글꼴을 가져오지 않습니다.
  하위 기능: 새 문서 레이아웃 / 고정 목차 / 이미지 확대 / 링크 · 각주 미리보기 / '표시' 패널 숨기기 / 본문을 지정한 너비 안에 맞추기
  문서 본문, 편집 진입 링크, 저작자 표시는 그대로 유지되며 외부 사이트로의 전송이나 자체적인 문서 가져오기는 하지 않습니다. 끄면 원래의 페이지 구성으로 돌아갑니다.

・📦 Amazon 정기배송 월별 합계(초기 상태 꺼짐)
  amazon.co.jp의 정기배송(Subscribe & Save) 관리 화면에 배송 월별 합계 금액(단가×수량)을 표시합니다. 목록에 가격이 없는 상품은 Amazon에서 현재 정기배송 가격을 가져오며, 가져올 수 없으면 이전 배송 단가로 참고용 합계를 계산합니다. 청구 금액은 달라질 수 있으며 쿠폰은 반영되지 않습니다. 모든 상품의 금액이 갖춰지지 않으면 일부만의 합계는 표시하지 않습니다.

・🏆 Amazon 랭킹 이동 버튼(초기 상태 꺼짐)
  상품 페이지마다 위치가 제각각인 '베스트셀러 랭킹' 링크를 상품 정보 맨 위의 버튼 하나로 모아 줍니다. 누르면 그 상품이 속한 가장 세부적인 하위 카테고리의 랭킹으로 이동합니다.

・📦 Amazon 판매자/배송 뱃지(초기 상태 꺼짐)
  상품 페이지에서 판매자와 배송처를 읽어 상품 정보 맨 위에 '판매: ○○ / 배송: ○○' 뱃지로 표시합니다. Amazon 직접 판매는 초록색, 마켓플레이스 판매는 주황색으로 구분하므로 구매 전에 판매자를 확인하기 쉽습니다.

・🔊 볼륨 부스터(초기 상태 꺼짐)
  탭의 볼륨을 0~300%로 조절합니다. 팝업을 연 탭에 적용되며, 이미 부스트 중인 탭은 탭을 전환해도 자동으로 다시 적용됩니다. 사이트 종류에 관계없이 사용할 수 있습니다.
  ・자동 왜곡 방지: 갑작스러운 큰 소리의 피크를 억제하여 부스트할 때의 소리 깨짐을 줄입니다
  ・야간 모드: 큰 목소리나 폭발음을 부드럽게 억제하여 작은 소리와의 차이를 줄입니다
  ・벽 울림 방지: 벽이나 바닥에 울리는 저음을 차단합니다
  ・10밴드 이퀄라이저: 32 Hz~16 kHz의 각 대역을 ±12 dB로 조정합니다. 프리앰프와 프리셋 9종이 포함되어 있습니다(직접 조정하면 '사용자 지정'으로 전환)
  ・음소거 버튼: 설정을 유지한 채 한 번의 클릭으로 음소거 및 복귀
  볼륨 100%에서도 이 하위 기능만 사용할 수 있습니다. 필요 없어지면 오디오 처리를 바로 해제합니다.

・🎞️ 영상 감마(초기 상태 꺼짐)
  페이지 위의 영상에 감마 보정을 적용합니다. 슬라이더의 가운데(1.0)가 보정 없음이며, 오른쪽으로 옮기면 어두운 부분을 끌어올려 밝게, 왼쪽으로 옮기면 대비를 높여 어둡게 합니다(0.3~3.0). 임베드된 영상을 포함한 모든 탭에 공통으로 적용되는 설정입니다.

・🖥️ 영상 검은 띠 제거(초기 상태 꺼짐)
  울트라와이드 모니터 등에서 영상의 위아래 · 좌우에 나타나는 검은 띠를 확대(가로세로 비율을 유지하며 확대) 또는 늘이기로 제거하여 화면을 가득 채워 표시합니다. 사용 중인 모니터의 가로세로 비율이나 해상도를 선택하면 영상별 형태는 자동으로 판별합니다.

・🔍 돋보기(초기 상태 꺼짐)
  마우스 커서를 따라 움직이는 원형 확대경입니다. 현재 화면을 정지 이미지로 가져와 확대하므로 일시정지한 영상의 세부도 확인할 수 있습니다. 배율은 1.5 / 2.5 / 4배, 렌즈 지름은 150~1000 px로 조정할 수 있습니다. 화면을 왼쪽 클릭하면 꺼집니다.

・🎨 컬러 피커(항상 사용 가능)
  스포이트로 화면 위의 색을 추출하여 HEX / RGB / HSL 중 원하는 형식으로 클립보드에 복사합니다. 색상 코드를 붙여넣어 등록할 수도 있습니다. 추출한 색은 최대 20개까지 기록으로 기기 안에 저장됩니다.

■ 사용 방법

1. 도구 모음의 아이콘을 클릭하여 팝업을 엽니다
2. 상단의 카테고리 선택에서 원하는 화면을 고릅니다
3. 각 기능의 스위치 · 슬라이더 · 선택란으로 설정합니다(변경 사항은 자동으로 저장되며 바로 반영됩니다)

볼륨 부스터 · 영상 감마 · 영상 검은 띠 제거 · 돋보기 · Amazon 3가지 기능은 '조정'에 있습니다. 마지막에 연 화면은 다음에도 유지됩니다.

■ 설정 저장 및 불러오기
'설정'에서는 브라우저의 동기화 기능을 이용한 여러 PC 간 설정 동기화와 JSON 파일로의 내보내기 · 불러오기를 할 수 있습니다. 모든 기능의 설정, 이퀄라이저, 제외한 채널, 색상 추출 기록, 표시 중인 화면을 저장하며 다른 PC나 Chrome / Firefox 사이에서 옮길 수 있습니다. 동기화 켜기/끄기, Gemini Notebook 전송 대상 계정, 인증 정보, 캐시, 페이지 위의 표시 위치는 기기별로 유지됩니다. 표시 언어는 9개 언어(일본어 · 영어 · 중국어〈간체 · 번체〉 · 한국어 · 스페인어 · 프랑스어 · 독일어 · 포르투갈어〈브라질〉)를 지원하며, 브라우저의 언어에 맞춰 전환될 뿐 아니라 팝업 제목 옆에서 직접 선택할 수도 있습니다. 라이트 · 다크 테마도 지원합니다.

■ 개인정보 보호

・설정은 일반적으로 사용 중인 기기 안에 저장됩니다. 선택 사항인 설정 동기화를 켠 경우에만 대상 설정을 브라우저의 동기화 서비스로 공유합니다. 게임 화면 확대 범위와 선택한 표시 언어는 기기 안에만 저장되며 동기화되지 않습니다
・열람 중인 페이지의 내용이나 탭의 오디오를 광고 · 분석 · 원격 측정 목적으로 수집하거나 전송하지 않습니다. 볼륨 부스터는 오디오를 증폭하여 재생할 뿐이며 녹음 · 저장 · 전송은 하지 않습니다
・외부와의 통신은 사용자가 조작하거나 켠 다음 기능에 필요한 경우로 한정됩니다
  - Instagram / TikTok / X 이미지 저장: 저장 버튼을 눌렀을 때만 각 서비스의 이미지 배포 서버에서 이미지를 가져옵니다(쿠키와 리퍼러는 보내지 않음)
  - YouTube 기능 확장: 다른 국가 채널 숨기기 · 구독 채널 전체 표시 및 그리드화 · 방송 시각 표시가 켜져 있을 때만 YouTube의 채널 소개 · 구독 채널 목록 · 동영상 페이지 등과 썸네일 이미지를 가져옵니다
  - Gemini Notebook 전송: 하위 기능을 켜고 전송 패널을 사용했을 때만 로그인한 Google 계정으로 Gemini Notebook과 통신하여 전송 대상 확인과 영상 등의 URL 추가를 수행합니다
  - Amazon 정기배송 월별 합계: 켜져 있을 때만 amazon.co.jp에서 가격을 읽어 옵니다. 주문이나 배송은 변경하지 않으며 결과는 페이지 안에만 보관합니다
  - 설정 동기화: 켠 경우에만 브라우저의 동기화 서비스를 사용합니다
  - 문의: 사용자가 양식을 제출했을 때만 입력 내용을 Kagayoi Support로 보냅니다
・개발자의 서버로 열람 데이터를 보내는 일은 없습니다
